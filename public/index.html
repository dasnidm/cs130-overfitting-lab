What is this experiment showing?

Each model is an ordinary least squares polynomial. Increasing its degree adds terms, so training RMSE cannot increase on the same data (apart from numerical rounding). Extra flexibility can also fit random fluctuations, raising error on independent test data.

The 50-sample view averages the RMSE at each degree over 50 independently generated training/test pairs. The fitted-curve panel continues to show the first sample. This reduces sampling noise in the error comparison; it does not force a U-shape.

Where do the numbers come from?

Discounts are drawn uniformly from 10% to 80%. The assumed mean revenue is μ = 2200 + 400z − 950z², where z = (discount − 45) / 35. Each day's revenue is y = μ + ε, with independent normal noise of standard deviation σ.

This quadratic relationship is a teaching assumption. It was not estimated from HUMANA data and cannot identify a real optimal discount. Test data come from the same distribution as training data; real promotions can involve changing inventory, timing, and customer demand.

All 2,000 test observations are used to compute each test RMSE. The metric is √[Σ(y − ŷ)² / n]. No test outcome is used in fitting. The test curve is for demonstration; choosing a production model from it would require another untouched test set.

Try these comparisons
  1. Keep the sample fixed and move model complexity from 1 to 12. Compare the two error curves.
  2. Switch to the 50-sample average, then increase the training sample size. Does the cost of extra flexibility change?
  3. Set random variation to €0. A quadratic model can now recover the assumed truth; a rising test-error curve need not appear.
Reproduce or save a result

“New sample” changes the random seed. “Reset” restores the starting settings. “Copy this experiment” copies a URL with the settings and seed. “Download run” saves those settings, all observations for the displayed sample, its fitted coefficients, and both error tables as JSON. Run files can document what the app actually showed.
